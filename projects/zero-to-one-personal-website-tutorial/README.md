# 从 0 到 1 构建一个个人网站

这是 chenjin.io 里的一个教程子项目，用来把“搭一个个人网站”拆成一条可执行路线：先想清楚网站要表达什么，再做出最小可上线版本，最后持续迭代内容和分发。

## 目标

完成一个能上线的个人网站，而不是只停留在设计稿或技术练习。

最终交付物：

- 一个清晰的个人定位和首页主张
- 一个最小可用的信息架构
- 一个可运行的 React + Vite + Tailwind 网站
- 一个部署到自定义域名的线上版本
- 一个后续内容更新和作品沉淀流程

## 适合谁

- 想建立个人品牌，但不知道第一版网站该放什么的人
- 有一点前端基础，想用真实项目串起 React / Tailwind / 部署流程的人
- 想把作品、方法论、服务或写作长期沉淀到一个自有入口的人

## 教程原则

- 先上线，再变漂亮。
- 先表达清楚，再增加功能。
- 先服务一个明确读者，再追求完整个人品牌。
- 每一步都留下可复用资产，不做一次性搭建。

## 建议节奏

用 4 个半天完成第一版：

- 第 1 个半天：定位、读者、网站边界
- 第 2 个半天：首页文案和信息架构
- 第 3 个半天：前端实现和基础适配
- 第 4 个半天：部署、域名、上线复盘

如果只有一天，就只完成最小版本：一句定位、一个首页、三个作品入口、一个联系方式。
