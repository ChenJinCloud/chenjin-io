# 上线检查清单

## 内容

- [ ] 首页第一屏能说清楚“我是谁 / 我解决什么问题 / 下一步去哪”
- [ ] 至少有 3 个可信信号：作品、经历、数据、客户、文章或项目
- [ ] 所有外链可打开
- [ ] 联系入口可用
- [ ] 没有占位文案、空按钮和未完成提示

## 视觉

- [ ] 桌面端首屏不拥挤
- [ ] 移动端文字不溢出
- [ ] 按钮、卡片、链接间距一致
- [ ] 深浅色模式都可读，如果项目支持主题切换
- [ ] 图片加载正常，且不影响核心内容理解

## 技术

- [ ] 本地构建通过
- [ ] 生产页面可访问
- [ ] 404 页面存在
- [ ] 页面标题和描述已配置
- [ ] favicon 已配置
- [ ] robots.txt 和基础 SEO 文件已检查

## 发布

- [ ] 域名解析生效
- [ ] HTTPS 正常
- [ ] 社交分享预览图可用
- [ ] 首页、作品页、联系入口都在手机上验证过
- [ ] 记录本次上线版本和下一步改进
